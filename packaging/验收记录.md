- WebView2 改为 `downloadBootstrapper`：复用系统已有运行时；缺少时从微软下载引导程序，自动联网补装。后端运行时与依赖仍内置。
- 轻量包 NSIS 构建通过；生成配置中的 `WEBVIEW2INSTALLERPATH` 和 `WEBVIEW2BOOTSTRAPPERPATH` 均为空，不嵌入运行时安装文件。
- 真实 NSIS 目录回归通过，新目录、空目录及中文/空格路径可用，非空目录、磁盘根目录与 Windows 子目录拒绝。
- 欢迎页说明联网要求；下载失败、无法启动运行时安装程序及安装失败均中止并返回失败状态；运行时安装路径增加正确引号处理。
- 本次安装/修复/卸载自动复测，以及模拟缺少运行时的下载失败测试，均在进程创建时被本机 Windows 应用控制拦截（WinError 4551），未实际运行，不能标记通过。没有修改系统安全设置。
- 系统缺少 WebView2 时的真实联网补装仍需在允许执行测试安装器的干净 Windows 环境中验收。
